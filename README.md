# homebrew-plmi

[플밍이 statusLine](https://github.com/sbwon-uglee/plmi-statusline) 을 brew 로 깔기 위한 탭.

```bash
brew install sbwon-uglee/plmi/plmi
plmi
```

Claude Code 를 다시 띄우면 상태줄에 나온다. 크기는 `plmi --size 36x16`, 떼는 것은
`plmi --uninstall` 이다.

포뮬러 원본은 본 저장소의 `packaging/plmi.rb` 다. 여기 것을 직접 고치지 말고 그쪽을
고쳐 옮긴다.
